# Forever Profession Helper（永恆專業助手）

魔獸世界：永恆（Classic）專業練級與跨角色庫存輔助插件。

## 目前版本 v0.1.0（開發測試版）
- 自動紀錄同伺服器已登入角色的專業技能及等級。
- 背包、銀行庫存快照；離線角色資料不是即時資料。
- 物品 Tooltip 顯示已記錄的跨角色庫存。
- 已觀察到的專業配方材料以綠色標記；不能判斷的材料標記為「未知」，**不會擅自判定可以出售**。
- 輸入 `/fph` 開啟概覽，`/fph scan` 手動重新掃描。

## 安裝
將本儲存庫的插件檔案放入遊戲的 `Interface/AddOns/ForeverProfessionHelper/` 目錄，重新載入 UI。

## 重要限制
本版尚未在永恆客戶端實測。完整 1～300 配方、訓練師座標、最低成本規劃、Auctionator、購物清單與採集練級指南仍待實作。未經完整資料驗證，不能可靠顯示「不需要」。

完整需求請見 [SPEC.md](SPEC.md)。
