# Forever Profession Helper（永恆專業助手）

WoW Forever 的專業材料與同伺服器跨角色庫存插件。

## v0.2.0（開發測試版）
新版新增 `RecipeDB.lua`，嘗試接入《永恆》配方資料庫 **LibProfessionDB-1.0**。此資料庫的 Forever v1.9.1 包含 2,511 個配方（截至 1.60.1.69977），涵蓋尚未學會的配方。**整合碼尚未經遊戲客戶端驗證，API 回傳結構也須實測確認；目前不應當作已完整可用。**

### 使用方法
1. 透過 [CurseForge 安裝 LibProfessionDB](https://www.curseforge.com/wow/addons/libprofessiondb)，選擇支援 **WoW Forever 1.60.1** 的版本（至少 v1.9.1），並安裝其必要依賴。
2. 將本插件資料夾放在 `Interface/AddOns/ForeverProfessionHelper/`。
3. 進遊戲輸入 `/fph db`：應回報已載入的配方數；若回報資料庫缺少、API 不相容或索引為空，請勿依賴負面材料判斷。
4. `/fph` 顯示已記錄的角色專業；每隻角色登入並打開一次銀行才能取得相對完整的庫存快照。

### 材料分類
- **需要（綠）**：配方索引發現有角色專業使用該材料。
- **不需要（紅）**：只針對一般交易材料、且配方資料庫已能完整覆蓋同服已記錄專業時顯示。只代表目前已知製造配方不使用，不代表物品無其他用途。
- **未知（無標記）**：無法可靠判斷時使用，尤其資料庫不可用或專業沒有覆蓋時。
